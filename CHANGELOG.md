# Changelog

## 0.4 (build 5) — 2026-10-25 — Initial public release package

- Explicit app icon filename and Dock icon loading at launch.
- Native Swift/AppKit window with persistent WKWebView session.
- Dock unread badge and delayed reset when the last unread counter disappears.
- Developer panel hidden at launch; toggle with ⌘⇧D or the View menu.
- Badge test and copyable diagnostics.
- English menus, developer panel, diagnostics, documentation and filenames.
- Public packaging: restored camera icon, reproducible universal build, detector tests, CI, documentation and MIT license.

Unread detection comes from the privately tested 0.4. Public packaging adds documentation, build tooling and the restored camera icon; it does not change unread detection. Earlier 0.1–0.3 builds were private prototypes and are not published here.
