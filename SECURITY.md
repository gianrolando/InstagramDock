# Security

Do not post credentials, cookies, session files or exploitable security details in public issues. For suspected vulnerabilities, use GitHub's private vulnerability reporting through the repository's Security tab if the maintainer has enabled it. If it is unavailable, open a minimal issue asking for a private contact channel without describing the exploit or including sensitive data.

Only the current release is maintained on a best-effort basis; no response-time guarantee is offered. This is an independent WebKit wrapper, not a security boundary for Instagram. Download releases only from the repository you trust and check the SHA-256 checksum when supplied.
